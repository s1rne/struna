# Струна

Струны в воздухе перед веб-камерой. Руками натягиваете струну, щипком за край меняете ноту, пальцем проводите сквозь струну и она звучит.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5190
npm run build      # статичная сборка в dist/
```

Камера работает только на `localhost` или по HTTPS. Без камеры можно играть мышью или касаниями.

## Жесты

| Действие | Камера | Мышь |
|---|---|---|
| Натянуть струну | щипок двумя руками в пустоте и развести руки, или щипок одной рукой и протянуть | зажать и протянуть |
| Сыграть | провести пальцем сквозь струну | провести курсором |
| Изменить ноту | щипок за край и потянуть | потянуть за край |
| Переместить | щипок за середину | потянуть за середину |
| Убрать | перенести к крестику вверху или сжать короче 60 px | так же |

Клавиши: `1`–`6` инструмент, `M` звук, `V` камера, `H` справка, `⌘Z` вернуть убранное.

## Как устроено

- **Руки.** MediaPipe Hand Landmarker (`@mediapipe/tasks-vision`), модель `public/models/hand_landmarker.task`, GPU с откатом на CPU. Точки сглаживает фильтр One Euro. Щипок меряется в 3D относительно размера ладони, с гистерезисом.
- **Щипок струны.** Палец, пересекший струну медленно, тянет ее за собой и срывает на 14–40 px. Быстрое пересечение звучит сразу; несколько струн за кадр звучат с задержкой по моменту пересечения, поэтому бой не сливается в аккорд.
- **Высота.** Длина относительно диагонали экрана: вдвое короче значит октавой выше, 0.8 диагонали дает E2. Нота притягивается к выбранному ладу. Если тянуть звучащую струну, высота плавно едет.
- **Звук.** AudioWorklet с расширенным Karplus-Strong: треугольная форма щипка с шумом, гребенка по точке щипка, интерполяция Эрмита для плавной перестройки. Дальше резонансы корпуса на биквадах, реверберация на сгенерированной импульсной характеристике, компрессор. «Свой звук» играет загруженный файл с перестройкой скорости; исходную ноту определяет автокорреляция.

```
src/
  audio/        движок, ворклет струн, пресеты, загрузка сэмпла
  vision/       трекер рук, фильтр One Euro
  input/        мышь и касания как виртуальные руки
  interaction/  жесты: захват, натяжение, щипок
  model/        струны, геометрия, сохранение
  music/        ноты и лады
  render/       отрисовка на canvas
```
